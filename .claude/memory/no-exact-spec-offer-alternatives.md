"if no supplier was able to quote what customer requested, then the customer support agent need to communicate with the customer and mention that no supplier was able to quote your exact spec. However, there were similar options such as xxxx which they can, are you willing to proceed with such option? if yes then we proceed in the normal workflow and accordingly dont consider the new spec as a deviation. if not then we just apologize to the customer in a professional way" (14 Sep 2026).

**Why:** we don't assume and we don't leave the customer guessing; a spec gap is resolved with the customer, not hidden.
**How to apply:** trigger only when no eligible quote matches a mandatory requested value but alternatives exist; sales_engineer builds the anonymised alternatives list, customer_support sends it (WhatsApp/email/portal, registered language, tracked loop). Yes → record acceptance, update the accepted spec, continue normally. No/silence → apology, inquiry closed, no fee. If any supplier quoted the exact spec, no offer — deviations just show as quoted in writing. Related: [[exact-specs-or-the-quote-is-held]], [[nothing-is-one-way]], [[always-name-the-seat]].
