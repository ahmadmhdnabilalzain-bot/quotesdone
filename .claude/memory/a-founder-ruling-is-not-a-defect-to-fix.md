A test showed a licence for another company overwrite the registered name. Claude called it a defect and told an agent to hold it, and the agent rewrote the ruling's check. It was founder ruling 1176 (7 Oct): "auto fill the name from the attachment instead of rejection". Reverted before merge.

**Why:** [[founder-rulings-are-the-holy-book]]. Only the founder narrows a ruling.

**How to apply:** before changing what a check pins, search founder_instruction for the subject. Raise a risk to him once; never change it.
