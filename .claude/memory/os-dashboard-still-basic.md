Founder, 10 Aug 2026, after opening the dashboard himself: *"you did a lot of UI upgrade, but I
don't think actually the OS has been upgraded. I went into the dashboard, and it looks extremely
basic still. Definitely not what I was expecting."*

**Why:** sessions have been scored against Row #3 (the Executive UI spec) and have been reporting
real, measured progress — 120/152 — while the thing he actually opens still reads as basic. A
rising scorecard and a disappointing screen are not a contradiction to argue away: the checks
measure whether a mechanism exists, runs, is read and reaches a screen, and a surface can pass all
four and still be thin. **His judgement of the screen is the ground truth, not the score.**

**How to apply:**
- Do not answer this with the 120/152 number. Open the surface, look at it, and say what is thin.
- Separate "the OS computes it" from "the OS presents it well". The estate computes far more than
  it shows — `graph_nodes` had 323 nodes and zero readers, and that pattern repeats.
- When a session reports UI progress, name the screen and what a founder would now see on it, not
  the count of checks that flipped.
