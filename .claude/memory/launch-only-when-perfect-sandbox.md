Founder, 1 Sep 2026, correcting me for suggesting a live pilot / "run one real inquiry to prove it works":

**QuotesDone cannot launch until it is PERFECT** — genuinely the smartest automated procurement marketplace in the world. You launch a marketplace once; real customers and suppliers then depend on it. Launching something unfinished, or testing with a real customer/supplier/inquiry and then editing code while real people register, is unacceptable.

**"Let's run one real inquiry / a small live pilot to prove it works" IS launching. Never propose it.** Do not frame a live run as validation. Do not re-pitch "prove it runs live" or "fund inference to see it work."

**Everything is proven in a SANDBOX before go-live:** synthetic/demo data ([[demo-fixture-convention]] ZZ DEMO / @example.invalid), isolated, aborted-transaction probes that commit nothing, cleaned up. That is how the whole funnel is validated end-to-end with no real participant and no real spend. See [[safe-marketplace-demo-rehearsal]].
