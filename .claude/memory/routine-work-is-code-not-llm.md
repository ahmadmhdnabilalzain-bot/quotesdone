Routine, repeated company operations are deterministic code, never paid model calls: monitoring, reporting, daily digests, PDFs, scheduling, IT checks and campaign lists. Use the LLM only where real judgement cannot be coded, and justify each use. The target is at least 90% of operations coded.
**Why:** founder, 24 Sep 2026: "such tasks because they are extremely simple. Try to keep them coded. We don't want to use LLM for company operations... In very rare scenario it will use the LLM." He is also wary of credits "going here and there for nothing" once OpenRouter is topped up. He tops it up only after the build is finished and verified (he said "tomorrow" on 24 Sep).
**How to apply:** before any seat duty calls a model, ask whether code can do it. Audit the existing duties for avoidable model calls before OpenRouter opens. Related: [[do-batch-work-on-the-subscription-not-paid-llm]], [[the-only-hard-rules-and-operating-doctrine]].
