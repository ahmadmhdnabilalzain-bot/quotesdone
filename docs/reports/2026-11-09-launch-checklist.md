## Summary for the founder

1. The list has 105 named items, not 107 (43 in security, 62 in operations). Every one of the 105 has one row below.
2. 95 items apply to us. 10 do not: passkeys, single sign-on, password reset, magic links, load balancing, read replicas, reverse proxies, API gateways, horizontal scaling, distributed tracing.
3. Of the 95: 47 are PRESENT, 42 are PARTIAL, 6 are MISSING. The 10 others are N-A.
4. Built and checked today: Docker, error pages, a public health endpoint, a PR template, a linter, Stripe return-URL limits, a safer webhook secret check, incident and restore runbooks, a tech-debt register, a local copy of the full database schema, and `.env.example`.
5. Everything marked "measured" was read in code today. Live settings were not read: point-in-time recovery, database SSL enforcement, sign-up settings, Vercel preview variables, live headers, whether the cron jobs ran. They are marked "not verified".
6. Launch-blocking, in priority order. (a) Supplier "verified phone" bug (H1): a supplier can swap in any number and keep the verified badge, which customers pay to see. Fix in progress (today), not yet merged or deployed.
7. (b) Sign-up settings (M2): if password sign-up is open and auto-confirmed, anyone can hold a session for an email they do not own. One production check settles it. (c) External uptime monitor: nobody outside the building will tell us the site is down; about 30 minutes, you hold the account. (d) One real restore drill, plus confirm point-in-time recovery is on: the 4-hour recovery time is a claim, not a test.
8. Also do before launch, cheap: turn on database SSL enforcement and restrict allowed addresses. Run one burst test on inquiry-to-quote and sign-in before paid ads. Run Lighthouse accessibility on 6 pages. Check live error reporting from the browser.
9. Nice-to-have, not blocking: unchecked file paths (M1, needs a leaked path to exploit), a second factor for admin accounts, 66 outbound calls with no timeout, circuit breakers for email, Stripe and WhatsApp, CODEOWNERS, a 1.0.0 tag and changelog, performance budgets, five missing indexes, replayable migrations (TD-10).
10. Honest limit: code merged is not code deployed. Today's edge-function fixes (return URLs, webhook compare) are in the repository; this document does not prove they are live.
