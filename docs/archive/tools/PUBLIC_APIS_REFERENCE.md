# public-apis — reference, not a package

Source: https://github.com/public-apis/public-apis

This repository is a curated **directory** of free public APIs, not installable software, so it is
recorded here as a standing reference rather than cloned into the toolbox. Its value is the list of
candidate free data sources that can feed agent knowledge and enrichment without a paid provider.

Categories most relevant to QuotesDone's agents (finance/tax, business data, government, geocoding,
currency, weather, open corporate registries) should be triaged against each role's needs during the
knowledge stage. Any API actually wired in must clear the founder's holds and the privacy rules —
never place customer or supplier data in a third-party request, and never adopt an API that requires
paid credit without the founder's decision.

To browse the current list: open the source URL, or `git clone --depth 1
https://github.com/public-apis/public-apis` into a scratch area when a working copy is needed.
