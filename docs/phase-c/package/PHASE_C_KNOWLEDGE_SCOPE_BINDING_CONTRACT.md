
# Knowledge Scope Binding Contract — Phase C

Phase C does not import, rewrite or certify professional knowledge.

It connects the identity and scope interface that later retrieval must use.

Required input:

- canonical role ID;
- department ID;
- task class;
- workflow/step;
- category/subcategory/overlay where relevant;
- jurisdiction;
- company stage;
- authority/risk class.

Required output:

- permitted company-core scopes;
- department scopes;
- role scopes;
- task/playbook scopes;
- category scopes;
- validated-experience scopes;
- exclusions;
- missing/orphan mappings;
- version/source metadata.

Phase C tests resolution and access boundaries only. It does not call embeddings or a language model.
