# Refund-Only Founder Approval

The only routine founder approval is a specific refund approve/reject decision.

Refund case preparation: Customer Success + Payments/Billing + Fraud/Legal/Trust & Safety where relevant.  
Founder decision: approve or reject the specific case.  
Execution: Payments & Billing Manager.  
Independent reconciliation: Financial Controller.  
Closure: customer/supplier records and communication updated.

Any non-refund task attempting to use `founder_approval_required=true` or an `awaiting_founder_approval` state must be refused.
