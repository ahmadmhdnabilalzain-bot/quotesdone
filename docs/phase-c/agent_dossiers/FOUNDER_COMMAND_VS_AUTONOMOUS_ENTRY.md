# Founder Command vs Autonomous Company Entry

## Scenario 1 — Founder manually gives an order

1. Founder writes to the Chief of Staff in the Command Center.
2. Chief of Staff preserves the exact text and resolves a canonical command intent.
3. If ambiguous, the Chief of Staff asks one clarification and creates no task.
4. If clear, command, plan, parent objective and initial tasks are committed atomically.
5. The frozen Phase B workflow retains its accountable owner.
6. Child tasks go to the exact step owners, specialists and reviewers.
7. Progress and final result roll up to the same founder command thread.
8. No routine approval returns to the founder, except a specific refund decision.

## Scenario 2 — Normal autonomous company operation

1. A customer, supplier, schedule, KPI, system or workflow event occurs.
2. The canonical event router selects the frozen workflow and exact step.
3. A task is created for the canonical accountable role.
4. Contributors, specialists and category overlays are invoked only when required.
5. Internal reviewer gates decide approve/reject/revision autonomously.
6. State, outcome and KPI update.
7. Managers diagnose blockers and generate corrective work.
8. Founder sees dashboards, material blockers and results—not routine approvals.
