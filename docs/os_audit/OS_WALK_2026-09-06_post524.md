# QuotesDone OS — button-by-button walk, 6 Sep 2026 (main cf34c63 = PR #524 merged)

Walked in the founder's own Chrome session (claude-in-chrome), read-only: navigation, tabs, filters,
open/expand/download only. Nothing typed that sends mail/WhatsApp, approves a refund or spends money.
URL: https://quotesdone.com/os. One row per control: label · what happened (nav / panel / download /
network + status / console errors) · PASS or FAIL. FAIL rules (founder, verbatim): not clickable; a report
that is not a PDF; a social post without a clickable platform link, or a draft without clickable media; a
finance report that is not a corporate PDF; anything routed to the founder's approval that is not a refund.

Method: the previous walker (post-523) injected a whole-page click harness and hung the tab. This walk clicks
module by module with the browser tools (find / click / read_page / get_page_text / network / console) —
no injected walker. The hung tab was closed and a fresh tab opened on the same URL; the founder's session
was reused, never signed in or out.

Production state before the walk (measured 13:50 UTC): fn_os_search on production already uses
`k.fts @@ plainto_tsquery('english', b.q)` (the post-523 fix is APPLIED); its file
scripts/sql/os_search_reads_knowledge_through_its_fts_index.sql and MANIFEST.txt line are now in this branch.
