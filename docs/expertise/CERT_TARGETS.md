## The two-part "done" test (per field)
1. **COVERAGE (free, doable now):** every flagship cert's official blueprint + tested BoK is in kb_chunks
   under the field's category. Measurable by source presence.
2. **PASS (needs the paid LLM path, currently HELD):** the agent scores a pass on a blind mock exam built
   from each cert's blueprint. This is the founder's real bar and cannot be proven while paid inference is
   on hold (zero-cost mandate). Coverage is deliverable now; pass-verification is gated on the hold lifting.
