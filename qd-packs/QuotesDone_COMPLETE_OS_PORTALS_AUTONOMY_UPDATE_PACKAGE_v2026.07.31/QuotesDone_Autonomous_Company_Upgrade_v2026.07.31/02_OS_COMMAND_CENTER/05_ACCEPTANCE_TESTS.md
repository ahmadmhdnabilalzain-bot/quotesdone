# Executive OS acceptance tests

- Executive Home shows no metric without timestamp/source/freshness.
- A failed data source displays unknown/degraded, not zero.
- Observe Mode cannot mutate supplier/customer/RFQ/finance records.
- Control Mode requires recent MFA and automatically expires.
- Every command can be previewed before execution.
- Every executed command produces one correlation ID and decision trace.
- Live stream can resume from cursor without duplicates.
- Employee workspace shows real KPI, authority and workload data.
- What-if output lists assumptions and sensitivity.
- Company graph respects permissions and does not expose secrets/PII.
- Provider outage still allows dashboards, search, deterministic commands and incident control.
- Desktop and mobile layouts pass accessibility and keyboard tests.
