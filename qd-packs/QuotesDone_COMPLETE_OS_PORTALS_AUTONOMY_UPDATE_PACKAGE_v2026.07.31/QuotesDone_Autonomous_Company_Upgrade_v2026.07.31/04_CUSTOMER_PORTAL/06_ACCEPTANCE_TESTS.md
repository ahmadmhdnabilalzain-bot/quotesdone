# Customer portal acceptance tests

- A nontechnical English or Arabic request routes to the correct category or asks a simple clarification.
- Deterministic rules select the next missing question.
- Inquiry cannot dispatch until mandatory information and redaction gates pass.
- Customer can view every valid quote.
- Top three are reproducible from stored score breakdown, not a model's undocumented preference.
- Model outage still returns deterministic comparison.
- Report explains inclusions, exclusions, deviations, evaluated cost and trade-offs.
- No supplier identity appears before reveal.
- Project and document access respects customer/organization permissions.
- Customer can inspect/export/delete stored preferences.
- Arabic journey and report pass RTL and content parity tests.
- Mobile web journey works from registration to reveal.
