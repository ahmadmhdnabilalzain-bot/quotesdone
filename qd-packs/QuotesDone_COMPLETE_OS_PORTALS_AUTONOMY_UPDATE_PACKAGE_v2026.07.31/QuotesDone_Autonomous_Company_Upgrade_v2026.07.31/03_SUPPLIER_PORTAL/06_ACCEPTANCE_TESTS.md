# Supplier portal acceptance tests

- Informal onboarding text maps to the correct 86-route category or asks a clarification.
- No legacy 16-category limitation remains.
- Catalogue import creates source-linked products and never invents absent specifications.
- Supplier can correct extracted products; changes are versioned.
- Opportunities are ranked by deterministic score with readable reasons.
- Supplier never sees customer identity before reveal.
- Quote dry run lists missing mandatory fields and does not publish a quote.
- Quote assistant never invents price/discount/warranty.
- Negotiation cannot send without supplier approval.
- Market insights enforce sample-size and freshness policies.
- Document expiry automatically changes eligibility and is recoverable after renewal.
- Mobile web journey works from onboarding to submitted quote.
