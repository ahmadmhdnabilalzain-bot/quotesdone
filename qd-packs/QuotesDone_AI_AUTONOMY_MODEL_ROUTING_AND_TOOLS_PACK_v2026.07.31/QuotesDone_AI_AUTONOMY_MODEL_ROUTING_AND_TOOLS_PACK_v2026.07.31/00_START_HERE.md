# QuotesDone AI Autonomy, Model Routing and Tools Pack

**Build date:** 31 July 2026  
**Basis:** the supplied production backend export, the 86-category knowledge corpus, the company-operations corpus, and the founder's autonomous-company requirements.

## What this pack does

This pack tells Claude Code how to:

1. close the remaining gap between a collection of agents and a measurable autonomous company;
2. connect the missing runtime services already assumed by the code;
3. reduce OpenRouter cost through deterministic logic, internal retrieval, cheap specialist models, caching and batching;
4. assign exact default, fallback and escalation models to the current and target employee roles;
5. make every employee operate through a closed loop: observe → diagnose → plan → act → measure → report → learn;
6. implement a supplier-outreach employee that changes strategy based on response and registration outcomes;
7. preserve legal, financial, privacy, security and destructive-action gates.

## Important

- Do **not** bind an employee permanently to one model. Bind task classes to model ladders and give each employee a default task profile.
- Do **not** send the full knowledge corpus to a model. Retrieve only the records needed for the current task.
- Do **not** let language models directly change money, permissions, legal status, supplier bans, production secrets or irreversible records.
- Do **not** scrape LinkedIn without written authorization. Use compliant public-company sources and approved APIs.
- Apply all changes to a branch and staging Supabase project first.
